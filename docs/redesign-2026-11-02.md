# Eva Lab redesign · 2026-11-02

Approved direction: a personal developer blog borrowing the clarity of an academic homepage, without academic branding or decorative landscapes. Use a near-white canvas, slate text, restrained blue links, modern typography and fine rules. Introduce Eva briefly, then put real writing first. Retain all articles, project descriptions, about text, routes and Chinese/English switching.

## Implementation plan

1. Extract all original Next.js page payloads into `site-source/content.json` before rewriting output. Keep the original body HTML and dates intact.
2. Add a standard-library Python static publisher in `site-source/build.py`, with configuration in `site-source/site.json`. Build home, archive, article, project, about and 404 pages directly into the existing GitHub Pages checkout.
3. Share presentation through `site-source/site.css` and `site-source/site.js`. Add accessible search, topic filters, year archives, mobile layouts and article heading navigation. Use only existing projects and biography; no mockup content.
4. Generate canonical metadata, language alternates, article structured data, sitemap, RSS and robots rules. Never link an untranslated article to a nonexistent translation.
5. Verify original bodies and routes, internal navigation, metadata and classifications with `python3 -m unittest discover -s site-source -p 'test_*.py'`. Check JavaScript syntax, preview desktop/mobile, and exercise filters and language navigation.
