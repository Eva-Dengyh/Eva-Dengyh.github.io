macOS 终端从零配置：自动补全 + 高亮 + 主题全套

Eva·2026.04.28·7 分钟阅读

 

适用环境：Apple Silicon Mac · zsh · Homebrew

前置条件

确认 Homebrew 已安装，否则先执行：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

第一步：安装 Oh My Zsh

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

安装完成后终端会自动切换到新的 zsh 配置，出现 ~/.zshrc 文件。

第二步：安装 Powerlevel10k 主题

git clone --depth=1 https://github.com/romkatv/powerlevel10k.git \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k

编辑 ~/.zshrc，找到 ZSH_THEME 行并修改：

# 找到这一行
ZSH_THEME="robbyrussell"

# 改为
ZSH_THEME="powerlevel10k/powerlevel10k"

第三步：安装字体（Nerd Font）

Powerlevel10k 需要支持图标的字体。通过 Homebrew 安装 Nerd Fonts 版的 Meslo：

brew install --cask font-meslo-lg-nerd-font

📝 该 cask 安装出的字体在系统中显示为 MesloLGS Nerd Font（含 Regular/Bold/Italic/Bold Italic 四个变体），与 P10k 官方文档里提到的 "MesloLGS NF" 来源略有差异，但完全兼容所有图标。

然后在终端 App 的偏好设置中，将字体改为该字体：

  • Terminal.app：偏好设置 → 描述文件 → 字体 → 选 MesloLGS Nerd Font
  • iTerm2：Preferences → Profiles → Text → Font → 选 MesloLGS Nerd Font

第四步：安装 zsh-autosuggestions（自动补全）

git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

第五步：安装 zsh-completions（扩展补全库）

git clone https://github.com/zsh-users/zsh-completions \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-completions

⚠️ 重要：zsh-completions 作为 OMZ 插件首次启用后，必须强制重建补全缓存才会生效（第八步里包含此操作）。

第六步：安装 zsh-syntax-highlighting（语法高亮）

通过 Homebrew 安装（不放在 Oh My Zsh 插件目录）：

brew install zsh-syntax-highlighting

第七步：配置 ~/.zshrc

用以下内容替换整个 ~/.zshrc（或按注释逐段合并到现有文件）：

# ── Powerlevel10k 即时提示（必须放最顶部）──────────────────────────
if [[ -r "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh" ]]; then
  source "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh"
fi

# ── 自定义补全目录加入 fpath（必须在 source oh-my-zsh.sh 之前）─────
# 不要在这里手动调 compinit，OMZ 会自己调一次，避免重复
fpath=("$HOME/.oh-my-zsh/custom/completions" $fpath)

# ── Oh My Zsh 基础配置 ─────────────────────────────────────────────
export ZSH="$HOME/.oh-my-zsh"
ZSH_THEME="powerlevel10k/powerlevel10k"

plugins=(
    git
    zsh-autosuggestions
    zsh-completions
)

source $ZSH/oh-my-zsh.sh

# ── 语法高亮（必须放最末尾）───────────────────────────────────────
# Apple Silicon 下 Homebrew 前缀固定为 /opt/homebrew，写死避免每次启动 fork 一次 brew
source /opt/homebrew/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh

# ── Powerlevel10k 用户配置 ────────────────────────────────────────
[[ ! -f ~/.p10k.zsh ]] || source ~/.p10k.zsh

第八步：重建补全缓存 & 重新加载

zsh-completions 首次启用必须强制重建 zcompdump，否则新增补全项不会生效：

rm -f ~/.zcompdump*
exec zsh

exec zsh 会用一个新的 zsh 进程替换当前 shell（比 source ~/.zshrc 更彻底，能让 instant prompt 也正常工作）。

首次加载会自动启动 p10k 配置向导，按提示依次选择：

  1. 1. 字体是否显示正常（菱形、锁图标等）→ 选 Yes / No
  2. 2. Prompt 风格 → 推荐 Rainbow 或 Lean
  3. 3. 编码字符集 → 推荐 Unicode
  4. 4. 显示项目 → 按需勾选（时间、目录、git 状态等）

向导结束后自动生成 ~/.p10k.zsh。

如需重新配置：

p10k configure

第九步：验证效果

功能验证方式
主题提示符应显示彩色图标和 git 分支
历史建议输入 ls，右侧出现灰色补全建议，按 → 接受
语法高亮输入已知命令显示绿色，未知命令显示红色
Tab 补全输入 git che 再按 Tab，显示候选列表
扩展补全输入 docker comp 再按 Tab，应能补全到 compose（来自 zsh-completions）
