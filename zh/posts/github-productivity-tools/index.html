开发工具

从终端到监控，值得收藏的 4 个 GitHub 效率工具

Eva·2026.04.01·3 分钟阅读

 

前言

今天推荐四个我最近在 GitHub 上发现的效率工具，全部开源免费，而且都很轻量。它们解决的不是“大而全”的问题，而是程序员日常工作中那些高频、琐碎但又绕不开的小需求，比如终端增强、剪贴板管理、键鼠数据统计和系统监控。单看每一个功能都不算复杂，但组合起来，确实能让日常使用电脑的体验提升不少。

1. WaveTerminal - AI 集成的终端

GitHub: https://github.com/wavetermdev/waveterm

一句话： 内置 AI 的跨平台终端。

核心功能

  • 🤖 Wave AI：能读懂终端输出，自动分析问题
  • 🔐 持久 SSH：网络断开自动重连，服务器重启也不怕
  • 📁 远程文件编辑：内置编辑器，直接改服务器上的文件
  • 📄 文件预览：支持 Markdown、图片、视频、PDF 直接预览
  • 🔌 支持多模型：OpenAI、Claude、Gemini、Ollama、LM Studio

适合谁

  • 需要天天用终端 + AI 辅助的人
  • 经常远程服务器的人

安装

# macOS
brew install wave-terminal

# 或直接下载：https://www.waveterm.dev/download

2. Maccy - 剪贴板管理

GitHub: https://github.com/p0deje/Maccy

一句话： macOS 专属的轻量级剪贴板管理器。

核心功能

  • ⌨️ 快捷键：Shift + Command + C 快速调出
  • 🔍 搜索：输入关键词快速找到历史记录
  • 📌 置顶：常用的剪贴内容可以置顶
  • 🔒 安全：会忽略某些被标记为机密或临时的剪贴板类型，也支持手动配置忽略规则

适合谁

  • 经常复制粘贴的人
  • 需要频繁切换不同内容的人

安装

brew install maccy

3. keyStats - 键盘鼠标统计

GitHub: https://github.com/debugtheworldbot/keyStats

一句话： 看看你每天打了多少字。

核心功能

  • ⌨️ 键盘统计：每天敲了多少个键
  • 🖱️ 鼠标统计：点击次数、移动距离、滚轮滚动距离
  • 📊 菜单栏显示：核心数据直接在菜单栏
  • 🔄 每日重置：凌晨自动清空当天数据

适合谁

  • 好奇自己工作效率的人
  • 想量化自己工作状态的人

安装

# macOS
brew tap debugtheworldbot/keystats
brew install keystats

# Windows
scoop bucket add keystats https://github.com/debugtheworldbot/scoop-keystats
scoop install keystats

4. Stats - 系统监控

GitHub: https://github.com/exelban/stats

一句话： macOS 菜单栏上的系统监控器。

核心功能

  • 📈 CPU/GPU 使用率
  • 💾 内存使用
  • 💿 磁盘使用
  • 🌐 网络流量
  • 🔋 电池电量
  • 🌡️ 传感器温度

适合谁

  • 不想打开活动监视器的人
  • 需要实时看系统状态的人

安装

brew install stats

总结

工具功能平台
WaveTerminalAI 终端macOS / Linux / Windows
Maccy剪贴板macOS
keyStats键鼠统计macOS / Windows
Stats系统监控macOS

这四个工具都免费开源，安装简单，内存占用低。

如果你也想提升工作效率，可以尝试一下 🚀
