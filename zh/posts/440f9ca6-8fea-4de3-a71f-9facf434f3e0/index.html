Claude Code CLI 快速教程：从环境搭建到批量处理的实用指令集

Eva·2026.03.01·2 分钟阅读

Claude Code 配置教程（以 Mac 系统为例）

一、 准备与安装

1. 必备工具

工具 用途 安装/下载地址
Node.js 运行环境 https://nodejs.org
Git 版本控制 https://git-scm.com

2. 检查基础环境
在终端中确认是否已安装：

node -v
git --version

3. 全局安装 Claude Code

npm install -g @anthropic-ai/claude-code

4. 验证安装

claude --version

二、 配置与启动

1. 配置环境变量
打开终端配置文件（使用 vim 或你习惯的编辑器，如 cursor）：

vim ~/.zshrc

在文件末尾追加以下内容并保存：

export ANTHROPIC_BASE_URL="https://******"
export ANTHROPIC_AUTH_TOKEN="******"

2. 重载配置文件
使刚添加的环境变量生效：

source ~/.zshrc

3. 启动 Claude
直接在终端输入：

claude

三、 常用指令速查

在 Claude Code 运行界面中，可使用以下 / 开头的指令进行快捷操作：

  • /help：显示全部可用命令
  • /exit：退出当前对话
  • /clear：清除当前对话历史
  • /rename <名称>：重命名会话
  • /resume [session]：恢复已命名会话
  • /model：切换模型
  • /review：AI 代码审查
  • /rewind：回退改动（代码/对话）
  • /cost：查看 Token 用量和费用消耗

更多指令详见官网：https://code.claude.com/docs/en/overview
