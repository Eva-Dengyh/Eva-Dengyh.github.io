Self-Hosting Supabase with Docker in Five Minutes

Eva·2026.04.02·2 min read

Original length: 428 Chinese characters; approximately 3 minutes to read.

Introduction

Supabase is an open-source alternative to Firebase, providing a database, authentication, storage, edge functions, and more.

The official Docker deployment lets you get it running locally in minutes.

1. Install Docker Desktop

If you do not have Docker Desktop, download it first:

👉 https://www.docker.com/products/docker-desktop

After installation, make sure Docker is running.

2. Clone the Supabase Repository


git clone https://github.com/supabase/supabase.git
cd supabase/docker

Copy the configuration file:


cp .env.example .env

3. Configure Dashboard Access

Open .env in vim or your preferred editor and find the Access to Dashboard section:

  DASHBOARD_USERNAME=username
  DASHBOARD_PASSWORD=pwd

Replace the values with your own username and password.

4. Start the Services

  docker compose up -d

The first startup downloads container images and takes a few minutes.

5. Open Supabase

Once startup is complete:

ServiceAddress
Dashboardhttp://localhost:8000
APIhttp://localhost:8000/rest/v1/
Studiohttp://localhost:8000/studio/

Sign in to the dashboard with the credentials you just configured.

6. Explore Supabase

The self-hosted version provides:

  • 📊 PostgreSQL database — full PostgreSQL access.
  • 🔐 User authentication — built-in email and social sign-in.
  • 📁 File storage — an object-storage service.
  • ⚡️ Edge functions — Deno / Edge Functions.
  • 📡 Realtime subscriptions — real-time data synchronization.

7. External Access (Advanced)

A self-hosted Supabase instance is accessible locally by default. To access it from outside your network, you can set up a tunnel:

  • Use a tool such as Cloudflare Tunnel, frp, or cpolar.
  • Expose local port 8000 through a public endpoint.
  • You can then access your Supabase service from anywhere.

Common Commands

Stop the Services

docker compose down

Restart the Services

docker compose restart

View Logs

docker compose logs -f

Suitable Uses

  • ✅ Local development and testing.
  • ✅ Private deployment.
  • ✅ Learning and research.
  • ⚠️ Not recommended for production in this guide; the official cloud service is suggested instead.
