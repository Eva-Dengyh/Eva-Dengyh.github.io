GitHub Weekly: Hermes, MarkItDown, and OpenScreen—Unlocking Productivity

Eva·2026.04.12·10 min read

 

This week, I selected three widely discussed, practical open-source projects setting new benchmarks in AI automation, document processing, and content creation.
Beyond winning recognition from developers, these projects address real pain points for developers and content creators:

  • Hermes Agent redefines the intelligence of AI assistants through a closed-loop self-learning mechanism
  • MarkItDown converts complex, diverse file formats into LLM-friendly Markdown
  • OpenScreen provides professional screen recording comparable to paid tools

Whether you develop AI, engineer data pipelines, or create content, these projects can substantially improve your productivity. Let's explore their design philosophies, core features, and practical use cases.

I. Hermes Agent — A Personal AI Assistant That Evolves

Project: https://github.com/NousResearch/hermes-agent

Statistics: ⭐ 61.2k | Forks 8.2k

Note: I plan to start a dedicated series explaining this project later.

Positioning

Hermes Agent is an open-source autonomous AI agent system from Nous Research. Its fundamental difference from ordinary AI chat tools is closed-loop self-learning: it creates skills from experience, accumulates memories, and continuously builds an understanding of the user across sessions, becoming smarter with use.

Core Architecture

The system is built on three core mechanisms:

1. Persistent Memory

  • Honcho-powered dialectical user modeling retains preferences, habits, and historical context across sessions
  • A built-in FTS5 full-text search engine combines with LLM summaries for cross-session semantic recall
  • Session trajectories can be compressed into model-training data, with support for the Tinker-Atropos RL submodule

2. Automatic Skill Generation

  • The agent can automatically create and refine skill modules following the agentskills.io open standard
  • Periodic nudges help persist knowledge, enabling a true self-improvement loop

3. Multiplatform Messaging Gateway

One AI assistant connects across major communication platforms—Telegram, Discord, Slack, WhatsApp, Signal, and Email—without configuring a separate assistant for each.

Supported Models and Runtime Environments

LLM providers: Nous Portal, OpenRouter (200+ models), z.ai, Kimi, MiniMax, OpenAI, and custom endpoints

Execution backends (choose one of six):

  • Local
  • Docker

  • Singularity (HPC environments)
  • Modal (serverless)

Operating systems: Linux, macOS, WSL2, and Android (Termux). Native Windows is unsupported; use WSL2.

Typical Use Cases

  • Personal automation: Schedule the agent to generate daily reports, back up files, and perform periodic audits
  • A unified cross-platform entry point: Talk to the same AI that remembers you, whether on Telegram or Slack
  • RL training-data collection: Generate batch trajectories to supply high-quality model-training data
  • Development assistance: Combine MCP servers and context files into an intelligent coding assistant that understands the whole project

II. MarkItDown — An All-purpose Document Converter Built for LLMs

Project: https://github.com/microsoft/markitdown

Statistics: ⭐ 102.9k | Forks 6.4k

Positioning

MarkItDown is a Python library from Microsoft's AutoGen team that aims to convert almost every common file format into Markdown. Unlike other document converters, its output prioritizes machine consumption by LLMs over human reading experience: it preserves structural semantics as far as possible rather than reproducing visual appearance.

Reaching more than 100,000 stars in a short period suggests it precisely addresses pain points in RAG, knowledge-base construction, and document-ingestion pipelines.

Supported Formats

CategoryFormats
Office documentsPDF, Word (DOCX), Excel (XLSX/XLS), PowerPoint (PPTX)
Web contentHTML, YouTube URLs with automatic subtitle and description extraction
Data formatsCSV, JSON, XML
MultimediaImages, including EXIF metadata and OCR text extraction; audio, with speech transcription
OtherEPUB ebooks and ZIP archives, with recursive processing of files inside

Core Capabilities

Structure preservation: Retains semantic structure such as heading levels, lists, tables, and hyperlinks so LLMs can understand how a document is organized.

Multimedia metadata extraction: Image conversion goes beyond OCR, also extracting EXIF metadata such as capture time, GPS coordinates, and device information into text.

LLM vision enhancement: Integrates vision models such as OpenAI's to automatically generate semantic image descriptions and improve discoverability.

Azure Document Intelligence integration: Optionally uses Azure's advanced OCR for scanned documents and complex layouts to substantially improve recognition accuracy.

Plugin architecture: Supports custom converter extensions and includes MCP server support for direct use with Claude Desktop.

Version Notes (Breaking Changes in v0.1.0)

  • Optional dependencies move to grouped installation, deprecating the monolithic format (still supported in newer versions)
  • convert_stream() now accepts only binary file objects, opened in rb mode
  • DocumentConverter changes from file paths to stream processing

Typical Use Cases

  • RAG knowledge-base construction: Batch-convert internal PDFs and Word documents to Markdown before embedding and storing them
  • LLM data-preprocessing pipelines: Use it as a standardized component in document ingestion
  • Multisource document integration: Process content from websites, files, and videos into a consistent output format
  • Automated report processing: Regularly convert Excel reports and PowerPoint presentations into text for LLM analysis

III. OpenScreen — Free Professional Screen Recording

Project: https://github.com/siddharthvaddem/openscreen

Statistics: ⭐ 28.4k | Forks 1.9k

Positioning

OpenScreen is an open-source alternative to Screen Studio, a highly regarded macOS screen-recording tool requiring a paid subscription. OpenScreen aims to provide the same core experience, completely free, without watermarks, for personal and commercial use. It is currently in beta, but stable, usable releases are already available.

Features in Detail

Recording Controls

  • Record a specific window or the full screen
  • Record microphone and system audio on independent channels with separate volume controls
  • Pause and resume during recording

Camera Effects

  • Automatic zoom: Automatically enlarges the focus area based on mouse position, simulating a camera operator following the action
  • Manual zoom: Precisely control zoom position, amount, and duration on the timeline
  • Depth-of-field effect: Add a blurred background to highlight the active area
  • Motion blur: Pan and zoom effects include realistic motion-blur transitions

Editing

  • A visual timeline editor powered by dnd-timeline
  • Trim video clips to remove unnecessary segments
  • Segment-specific speed changes: accelerate dull portions and slow down detailed demonstrations
  • Crop video to hide or remove areas that should not be shown

Visual Customization

  • Background options: system wallpapers, solid colors, gradients, and custom images
  • Rounded corners, shadows, and other window enhancements produce professional floating-window demos in one click

Annotation Tools

  • Text annotations with customizable fonts, colors, and sizes
  • Directional arrows
  • Insert images such as logos and screenshots

Export Options

  • Multiple resolutions: 720p, 1080p, 2K, and 4K
  • Multiple aspect ratios: 16:9, 4:3, 1:1, portrait, and more
  • Common formats including MP4 and GIF

Download the installer for your platform from GitHub Releases:

On macOS, grant Screen Recording and Accessibility permissions in System Settings → Privacy & Security.

Typical Use Cases

  • Product demo videos: Record SaaS workflows with automatic zoom and polished backgrounds to produce professional demonstrations directly
  • Technical tutorials: Improve code walkthroughs and command-line demonstrations with speed adjustments and annotations
  • Design-review recordings: Record Figma prototype walkthroughs and add arrows and text to explain design intent
  • Customer-support videos: Record operating steps for users in place of written instructions
