Setting Up a macOS Terminal: Suggestions, Syntax Highlighting, and Themes

Eva·2026.04.28·4 min read

Environment: Apple Silicon Mac · zsh · Homebrew

Prerequisites

Make sure Homebrew is installed. If it is not, run:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Step 1: Install Oh My Zsh

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

After installation, the terminal switches to the new zsh configuration and creates ~/.zshrc.

Step 2: Install the Powerlevel10k Theme

git clone --depth=1 https://github.com/romkatv/powerlevel10k.git \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k

Edit ~/.zshrc, find the ZSH_THEME line, and change it to:

# 找到这一行
ZSH_THEME="robbyrussell"

# 改为
ZSH_THEME="powerlevel10k/powerlevel10k"

Step 3: Install a Nerd Font

Powerlevel10k needs a font with icon support. Install the Nerd Fonts version of Meslo through Homebrew:

brew install --cask font-meslo-lg-nerd-font

📝 The font installed by this cask appears in the system as MesloLGS Nerd Font, with Regular, Bold, Italic, and Bold Italic variants. Its source differs slightly from the “MesloLGS NF” mentioned in the official P10k documentation, but it is fully compatible with all the icons.

Then select this font in your terminal application's preferences:

  • Terminal.app: Preferences → Profiles → Font → choose MesloLGS Nerd Font
  • iTerm2: Preferences → Profiles → Text → Font → choose MesloLGS Nerd Font

Step 4: Install zsh-autosuggestions

git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

Step 5: Install zsh-completions

git clone https://github.com/zsh-users/zsh-completions \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-completions

⚠️ Important: After enabling zsh-completions as an OMZ plugin for the first time, you must force a rebuild of the completion cache before it takes effect. Step 8 includes this operation.

Step 6: Install zsh-syntax-highlighting

Install it through Homebrew, rather than in the Oh My Zsh plugin directory:

brew install zsh-syntax-highlighting

Step 7: Configure ~/.zshrc

Replace the entire ~/.zshrc with the following, or use the comments to merge each section into your existing file:

# ── Powerlevel10k 即时提示（必须放最顶部）──────────────────────────
if [[ -r "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh" ]]; then
  source "${XDG_CACHE_HOME:-$HOME/.cache}/p10k-instant-prompt-${(%):-%n}.zsh"
fi

# ── 自定义补全目录加入 fpath（必须在 source oh-my-zsh.sh 之前）─────
# 不要在这里手动调 compinit，OMZ 会自己调一次，避免重复
fpath=("$HOME/.oh-my-zsh/custom/completions" $fpath)

# ── Oh My Zsh 基础配置 ─────────────────────────────────────────────
export ZSH="$HOME/.oh-my-zsh"
ZSH_THEME="powerlevel10k/powerlevel10k"

plugins=(
    git
    zsh-autosuggestions
    zsh-completions
)

source $ZSH/oh-my-zsh.sh

# ── 语法高亮（必须放最末尾）───────────────────────────────────────
# Apple Silicon 下 Homebrew 前缀固定为 /opt/homebrew，写死避免每次启动 fork 一次 brew
source /opt/homebrew/share/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh

# ── Powerlevel10k 用户配置 ────────────────────────────────────────
[[ ! -f ~/.p10k.zsh ]] || source ~/.p10k.zsh

Step 8: Rebuild the Completion Cache and Reload

When enabling zsh-completions for the first time, you must force a rebuild of zcompdump; otherwise, the additional completions will not work:

rm -f ~/.zcompdump*
exec zsh

exec zsh replaces the current shell with a fresh zsh process. This is more thorough than source ~/.zshrc and also lets instant prompt work correctly.

The first load automatically starts the p10k configuration wizard. Follow its prompts:

  1. Check whether font symbols such as diamonds and locks display correctly → choose Yes or No.
  2. Choose a prompt style → Rainbow or Lean is recommended.
  3. Choose a character set → Unicode is recommended.
  4. Select the items you want displayed, such as time, directory, and Git status.

The wizard automatically creates ~/.p10k.zsh.

To run the configuration again:

p10k configure

Step 9: Verify the Result

FeatureHow to check
ThemeThe prompt should display colored icons and the Git branch.
History suggestionsType ls. A gray suggestion should appear to the right; press → to accept it.
Syntax highlightingKnown commands should appear green and unknown commands red.
Tab completionType git che and press Tab to see completion candidates.
Extended completionsType docker comp and press Tab. It should complete to compose, provided by zsh-completions.
