GitHub Weekly: AI Projects Worth Watching

Eva·2026.04.06·7 min read

 

1,727 Chinese characters; approximately 9 minutes to read

The open-source community has been moving at an outrageous pace lately, especially in AI coding tools: a new “champion” seems to emerge almost daily. To save everyone time filtering through them, I am starting a new series: a weekly deep dive into the top three—or most noteworthy—projects on GitHub Trending.

This week's preview:

1.claw-code - A Rust version of the Claude Code CLI, the fastest project ever to reach 100,000 stars
2. oh-my-codex - An enhancement toolkit for Codex, complete with workflows, agent teams, and a HUD
3. claude-howto - A practical introductory guide to Claude Code: from beginner to proficiency in 11–13 hours
4. VibeVoice - Microsoft's open-source speech AI, supporting 50+ languages, with long-audio processing as a highlight

1. claw-code: The Fastest Project Ever to Reach 100,000 Stars

  • GitHub: ultraworkers/claw-code
  • Stars: 172k
  • Language: Rust

What It Is

claw-code is an open-source Rust implementation of the Claude Code CLI. Anthropic's official version is TypeScript-only; this is the community's Rust rewrite. Interestingly, the project itself was built with oh-my-codex—something of a “build itself” story.

Core Contents

  • Rust implementation: A Rust rewrite of the Claude Code CLI
  • Workspace: A complete Rust workspace
  • CLI: A command-line interface similar to Claude Code
  • Tests: A companion Python reference workspace and auditing tools

Quick Start

cd rust
cargo build --workspace
./target/debug/claw --help
./target/debug/claw prompt "summarize this repository"

Authentication methods:

export ANTHROPIC_API_KEY="sk-ant-..."
# 或者
cd rust
./target/debug/claw login

My Take

What does 100,000 stars mean? It reached that milestone in just a few days, faster than any project before it. The reason it took off is simple: this week, 500,000 lines of Claude Code's TypeScript source leaked through source maps. This project is a Rust version of Claude Code, with better performance and easier deployment. If you like Claude Code but want Rust's performance, it is worth watching.

2. oh-my-codex: Turn Codex into a “Workstation”

GitHub: Yeachan-Heo/oh-my-codex
Stars: 16,941
Language: TypeScript

What It Is

oh-my-codex, or OMX, is an enhancement toolkit for OpenAI's Codex CLI. Its official description is a “workflow layer”: it wraps Codex in a better workflow. In simple terms, it makes a previously solo Codex more capable, adding hooks, agent teams, a HUD, and customizable workflows.

Core Features

  1. 1. Standard workflow: Use $deep-interview to clarify requirements → $ralplan to plan → $ralph to keep executing → $team for parallel collaboration
  2. 2. Agent teams: Multiple agents working together, with persistent execution through tmux
  3. 3. Persistent state: Stores plans, logs, memories, and runtime state in the .omx/ directory
  4. 4. HUD interface: Monitors agent activity in real time
  5. 5. Skills extensions: Includes a set of common skills

Who It Is For

  • People already familiar with Claude Code who want to improve efficiency
  • People handling complex tasks who want multiple agents to collaborate
  • People who want to turn Codex into a complete workbench

Quick Start

npm install -g @openai/codex oh-my-codex
omx setup
omx --madmax --high

Then use Codex as usual, with a few additional commands:

  • $deep-interview "..." - Clarify the boundaries of the requirements
  • $ralplan "..." - Create and approve a plan
  • $ralph "..." - Continue executing until completion
  • $team 3:executor "..." - Execute in parallel

My Take

There is a reason this project is popular. Codex itself is powerful, but it lacks a standardized framework for getting the most out of it. OMX fills that gap, and its thinking resembles OpenClaw's in some ways: both add workflows, state management, and multi-agent collaboration. If you use Codex, give it a try.

3. claude-howto: A Practical Introductory Guide to Claude Code

GitHub: luongnv89/claude-howto
Stars: 20,707
Language: Python

What It Is

This is a visual introductory guide to Claude Code, covering everything from basic concepts to advanced agents. Most importantly, it provides plenty of copy-and-paste templates you can use immediately.

The Problem It Solves

Many people install Claude Code and know how to use it, but do not know what else it can do:

  • Official documentation explains features without teaching how to combine them
  • There is no clear learning path
  • Examples are too basic; “hello world” demonstrations cannot be used in production

This project addresses those problems.

Content Structure

Ten tutorial modules cover all Claude Code features:

  • Slash Commands (basics)
  • Memory
  • Checkpoints
  • CLI Basics
  • Skills
  • Hooks
  • MCP (Model Context Protocol)
  • Subagents
  • Advanced Features

Each module includes visual Mermaid diagrams, ready-to-copy configuration templates, and an estimated learning time.

Learning Paths

LevelWhat you can doStart hereTime
BeginnerLaunch Claude Code and chatSlash Commands~2.5h
IntermediateUse CLAUDE.md and custom commandsSkills~3.5h
AdvancedConfigure MCP servers and hooksAdvanced Features~5h

Completing all 10 modules takes approximately 11–13 hours.

Notable Features

  • Self-assessment quiz: Run /lesson-quiz or /self-assessment to identify gaps in your knowledge
  • Personalized paths: Recommends what to learn next based on your current proficiency
  • Production-ready templates: Actual project configurations, not simple demos

My Take

This project is particularly suitable for newcomers to Claude Code. The official documentation is good, but scattered, without a clear route through it. This guide connects that scattered knowledge, and its templates really are ready to use. More than 20,000 stars suggest others find it useful too.

4. VibeVoice: Microsoft's Open-Source Speech AI

GitHub: microsoft/VibeVoice
Stars: 36,564
Language: Python

What It Is

VibeVoice is Microsoft's open-source speech AI family, covering speech recognition (ASR) and speech synthesis (TTS). Its key innovation is a continuous speech tokenizer with an extremely low frame rate of 7.5 Hz, substantially improving computational efficiency while preserving audio quality. It supports processing audio up to 60 minutes long in one pass.

Main Models

ModelPurposeTry it
VibeVoice-ASR-7BSpeech recognitionPlayground
VibeVoice-TTS-1.5BSpeech synthesisColab
VibeVoice-Realtime-0.5BReal-time speech synthesisColab

Supported Features

  • Multilingual: Supports 50+ languages
  • Long audio: ASR supports 60 minutes per pass; TTS supports 90 minutes of synthesis
  • Multiple speakers: TTS supports up to four distinct speakers
  • Fine-tuning: Includes fine-tuning code for training your own model
  • vLLM inference: Supports fast inference deployment
  • HuggingFace Transformers: Integrated into Transformers v5.3.0

Real-World Applications

The open-source community has already adopted the project. Vibing, a voice-driven input method built on VibeVoice-ASR, supports macOS and Windows.

My Take

Microsoft has put real effort into this release. Although the TTS code was previously taken down for various reasons, the newly open-sourced ASR and Realtime TTS are both strong. Thirty-six thousand stars is a high figure in speech technology. If you want to build speech applications, this is worth following.

Summary

Toolchain integration is the defining theme of this week's rankings.
We are moving from “tuning a single AI” to “managing an AI team.” Whether it is OMX's workflows or claw-code's high-performance foundation, the message is the same: coding in 2026 is no longer a contest of typing speed, but of your ability to build and manage Agent workflows.

That wraps up this edition of GitHub Trending Watch.
