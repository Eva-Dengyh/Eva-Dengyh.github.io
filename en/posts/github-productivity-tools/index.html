From Terminals to Monitoring: Four GitHub Productivity Tools Worth Keeping

Eva·2026.04.01·3 min read

Introduction

Here are four productivity tools I recently found on GitHub. They are all free, open source, and lightweight. Rather than trying to do everything, they address small but frequent needs that developers cannot avoid: better terminals, clipboard management, keyboard and mouse statistics, and system monitoring. None is especially complicated on its own, but together they can noticeably improve everyday computer use.

1. WaveTerminal — A Terminal with Integrated AI

GitHub: https://github.com/wavetermdev/waveterm

In one sentence: a cross-platform terminal with built-in AI.

Core Features

  • 🤖 Wave AI: Reads terminal output and automatically analyzes problems.
  • 🔐 Persistent SSH: Reconnects after network interruptions, including server restarts.
  • 📁 Remote file editing: A built-in editor lets you edit server files directly.
  • 📄 File previews: Preview Markdown, images, videos, and PDFs in place.
  • 🔌 Multiple model options: OpenAI, Claude, Gemini, Ollama, and LM Studio.

Who It Is For

  • People who use a terminal and AI assistance every day.
  • People who frequently work on remote servers.

Installation

# macOS
brew install wave-terminal

# 或直接下载：https://www.waveterm.dev/download

2. Maccy — Clipboard Management

GitHub: https://github.com/p0deje/Maccy

In one sentence: a lightweight clipboard manager exclusively for macOS.

Core Features

  • ⌨️ Shortcut: Open it quickly with Shift + Command + C.
  • 🔍 Search: Find clipboard history by keyword.
  • 📌 Pinning: Keep frequently used clips pinned.
  • 🔒 Security: Ignores certain clipboard types marked confidential or temporary, and supports custom ignore rules.

Who It Is For

  • People who copy and paste frequently.
  • People who often switch between different pieces of content.

Installation

brew install maccy

3. keyStats — Keyboard and Mouse Statistics

GitHub: https://github.com/debugtheworldbot/keyStats

In one sentence: see how much you type every day.

Core Features

  • ⌨️ Keyboard statistics: Count daily keystrokes.
  • 🖱️ Mouse statistics: Track clicks, movement distance, and scroll distance.
  • 📊 Menu-bar display: See key metrics directly in the menu bar.
  • 🔄 Daily reset: Automatically clears the daily counters at midnight.

Who It Is For

  • People curious about their productivity.
  • People who want to quantify their work habits.

Installation

# macOS
brew tap debugtheworldbot/keystats
brew install keystats

# Windows
scoop bucket add keystats https://github.com/debugtheworldbot/scoop-keystats
scoop install keystats

4. Stats — System Monitoring

GitHub: https://github.com/exelban/stats

In one sentence: a system monitor in the macOS menu bar.

Core Features

  • 📈 CPU/GPU utilization.
  • 💾 Memory usage.
  • 💿 Disk usage.
  • 🌐 Network traffic.
  • 🔋 Battery level.
  • 🌡️ Sensor temperatures.

Who It Is For

  • People who would rather not open Activity Monitor.
  • People who need a live view of system status.

Installation

brew install stats

Give them a try if you want to improve your workflow. 🚀
