Bringing Codex into Claude Code: A Dual-Engine AI Coding Workflow

Eva·2026.03.31·3 min read

1. Introduction

Today OpenAI quietly released something new: codex-plugin-cc (https://github.com/openai/codex-plugin-cc/tree/main). In simple terms, this plugin lets you call OpenAI Codex directly from Claude Code to review code and fix bugs.

2. What Is Codex?

Before discussing the plugin, a brief introduction to Codex.

Codex is OpenAI's AI coding assistant for writing code, reviewing it, and fixing bugs. It belongs to the same category as Claude Code and Cursor, but is backed by OpenAI. Previously it mainly ran on its own; this plugin now lets you use it within Claude Code.

3. What Can the Plugin Do?

1. Code Review

/codex:review

One command asks Codex to review your current uncommitted changes. The review is read-only and does not modify your code.

It supports:

  • Reviewing current changes.
  • Reviewing the differences between a branch and main.
  • Running in the background without blocking your work.

2. Adversarial Review

/codex:adversarial-review challenge whether the caching design is right

This is one of the features I find especially interesting.

A normal review looks for bugs. An adversarial review also challenges your design decisions:

  • Does this design really make sense?
  • Is there a better approach?
  • What trade-offs are involved?

It is like inviting a deliberately skeptical reviewer to focus on the weaknesses in your design.

3. Delegating Tasks

/codex:rescue investigate why the tests are failing /codex:rescue fix the failing test

Ask Codex directly to investigate a problem and attempt a fix.

You can specify a model:

  • -model spark selects the latest, most capable model described in this article.
  • -model gpt-5.4-mini selects a smaller, faster model.
  • -effort medium controls the level of effort.

4. Automated Review Gates

/codex:setup --enable-review-gate

With this enabled, Claude Code automatically triggers a Codex review whenever you are ready to ship. If the review finds problems, shipping is blocked.

This is useful for teams that want every code submission reviewed.

4. Technical Implementation

The plugin's stack is straightforward:

  • Invocation: Calls the Codex service through the local @openai/codex CLI.
  • Authentication: Reuses a Codex account without requiring a separate login.
  • Configuration: Supports user-level ~/.codex/config.toml settings and project-level configuration.

In other words, if Codex is already installed locally, the plugin is ready to use.

5. Installation

Prerequisites:

Node.js 18.18+ and a Codex account, using either a ChatGPT subscription or an API key.

Add the marketplace in Claude Code:

/plugin marketplace add openai/codex-plugin-cc

Install the plugin:

/plugin install codex@openai-codex

Reload the plugin:

/reload-plugins

Check Codex. If it is missing and npm is available, this can install it for you:

/codex:setup

6. Summary

The Codex Plugin for Claude Code essentially connects two AI coding tools:

  • Claude Code: Everyday programming and interactive conversation.
  • Codex: Focused code review and repairs.

One emphasizes interaction, the other review. Together they provide a complete coding-and-review workflow.

If you already use both tools, the plugin is worth trying.
