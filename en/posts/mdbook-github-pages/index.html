Publishing Markdown Notes with mdBook and GitHub Pages

Eva·2026.04.10·9 min read

 

All articles from this WeChat account are also organized in the GitHub repository https://github.com/Eva-Dengyh/AI-Fullstack-Notes. The repository versions include more complete code examples, supplementary explanations, and subsequent updates. If you find them helpful, star ⭐ the repository to bookmark it, and feel free to report errors or discuss ideas through Issues.

Scenario: You have a collection of Markdown notes and want to organize them into an online “technical book” with navigation and search, automatically published every time you git push. mdBook + GitHub Pages + GitHub Actions can do all this in 30 minutes, completely free.

This article covers:

  • Local installation and initialization
  • Directory structure and SUMMARY.md writing rules
  • book.toml complete configuration guide
  • Customizing appearance (theme colors, fonts, favicon)
  • Automated deployment with GitHub Actions, .gitignore, and Pages settings

1. Prerequisites

ToolVersion requirementDescription
Rust / CargoAny stable releaseUsed to install mdBook through cargo install
Git≥ 2.xVersion control and pushing
GitHub account—Repository hosting + Pages deployment

If you do not want to install Rust, download a precompiled binary from GitHub Releases and put it on your PATH.

2. Install mdBook

Option A: Install through Cargo (Recommended)

cargo install mdbook

Verify after installation:

mdbook --version
# 常见为 v0.5.x（与 CI 里 mdbook-version: "latest" 一致）
# 若需与旧版插件兼容，可固定为 0.4.x，例如：cargo install mdbook --locked --version 0.4.52

Option B: Download a Binary (No Rust Required)

# macOS (Apple Silicon)
curl -L https://github.com/rust-lang/mdBook/releases/latest/download/mdbook-aarch64-apple-darwin.tar.gz \
  | tar xz -C /usr/local/bin

# Linux x86_64
curl -L https://github.com/rust-lang/mdBook/releases/latest/download/mdbook-x86_64-unknown-linux-gnu.tar.gz \
  | tar xz -C /usr/local/bin

3. Initialize the Project

3.1 New Project

mdbook init my-notes
cd my-notes

init generates this structure:

my-notes/
├── book.toml        # 核心配置文件
└── src/
    ├── SUMMARY.md   # 目录（mdBook 的"地图"）
    └── chapter_1.md

3.2 Use an Existing Markdown Repository

If you already have a Git repository containing .md files, run this directly at its root:

mdbook init --force .

Then manually adjust the book.toml file's src path (explained in the next section).

Note: mdbook build defaults to the output directory book/ at the repository root. Add the root-level .gitignore entry for book/ early (see Section 9). Do not commit book/ as a submodule; otherwise, it will have no URL in .gitmodules and CI will fail when actions/checkout tries to fetch submodules.

4. Complete book.toml Configuration Guide

book.toml is mdBook's main configuration file, in TOML format. Below is a complete, production-ready configuration with line-by-line comments:

# ── 书籍基本信息 ──────────────────────────────────────────
[book]
title       = "AI-Fullstack-Notes"          # 显示在左上角的书名
description = "全栈工程师的 AI/Agent 学习笔记"
authors     = ["Eva"]
language    = "zh"                           # 界面语言（影响搜索分词）
src         = "."                            # Markdown 源文件根目录
                                             # 默认 "src"；改成 "." 表示仓库根目录即源目录

# ── HTML 输出配置 ─────────────────────────────────────────
[output.html]
site-url = "/AI-Fullstack-Notes/"           # GitHub Pages 子路径，必须与仓库名一致
                                             # 本地预览时注释掉此行，否则资源路径会错

git-repository-url  = "https://github.com/Eva-Dengyh/AI-Fullstack-Notes"
# mdBook 0.5+：品牌图标 fa-github 等会触发构建错误 Missing font github，请省略 git-repository-icon。
# git-repository-icon = "fa-github"

# 每个页面底部显示"在 GitHub 上编辑此页"链接
edit-url-template = "https://github.com/Eva-Dengyh/AI-Fullstack-Notes/edit/main/{path}"

# 其他常用可选项（按需启用）：
# theme            = "coal"                 # 默认主题：light/rust/coal/navy/ayu
# default-theme    = "light"               # 读者首次打开时的主题
# preferred-dark-theme = "navy"            # 系统暗色模式时使用的主题
# mathjax-support  = true                  # 启用 LaTeX 数学公式
# no-section-label = true                  # 目录标题前不显示章节编号
# additional-css   = ["theme/custom.css"]  # 自定义 CSS
# additional-js    = ["theme/custom.js"]   # 自定义 JS
# search.enable    = true                  # 默认开启全文搜索

A key pitfall: site-url must exactly match your GitHub repository name, including capitalization; otherwise, image and CSS paths will all return 404 after deployment.

5. Rules for Writing SUMMARY.md

SUMMARY.md is the only entry point through which mdBook reads the table of contents. File paths are relative to the src directory (the directory specified by book.toml's src setting).

5.1 Basic Syntax

# 目录

<!-- 前言：不计入章节编号，显示在最顶部 -->
[前言](README.md)

---

# 一级分组标题（纯文本，不可点击）

- [章节标题](path/to/file.md)
  - [子章节](path/to/sub.md)
    - [孙章节](path/to/subsub.md)

# 另一个分组

- [另一章](another.md)

---

<!-- 后记：不计入章节编号 -->
[附录](appendix.md)

6. Local Preview

# 启动本地开发服务器，文件变动自动刷新
mdbook serve --open

# 仅构建，不启动服务器
mdbook build
# 输出目录：./book/

For local previews, if book.toml sets site-url = "/AI-Fullstack-Notes/", visiting http://localhost:3000 shows a blank page. Temporarily comment out that line, or access it through http://localhost:3000/AI-Fullstack-Notes/.

7. Customize the Appearance (Optional)

7.1 Override Theme Variables

Create a theme/ folder at the project root and add custom.css: 

/* theme/custom.css */
:root {
  --sidebar-bg: #1a1a2e;        /* 侧边栏背景色 */
  --sidebar-fg: #e0e0e0;        /* 侧边栏文字色 */
  --links: #4fc3f7;             /* 链接颜色 */
}

Reference it in book.toml:

[output.html]
additional-css = ["theme/custom.css"]

7.2 Add a Favicon

mkdir -p theme
cp your-favicon.png theme/favicon.png
# 或 .ico 格式
cp your-favicon.ico theme/favicon.ico

mdBook automatically recognizes theme/favicon.png or theme/favicon.ico; no extra configuration is needed.

7.3 Enable MathJax (Mathematical Formulas)

[output.html]
mathjax-support = true

Usage:

行内公式：$E = mc^2$

块级公式：
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

8. Automated Deployment with GitHub Actions

8.1 Directory Structure

your-repo/
├── .github/
│   └── workflows/
│       └── deploy.yml   ← 新建此文件
├── book.toml
├── SUMMARY.md
├── .gitignore           ← 建议：忽略 book/（见第九节）
└── ...（你的 .md 文件）

8.2 Complete deploy.yml

name: Deploy mdBook to GitHub Pages

on:
  push:
    branches:
      - main          # 只有推送到 main 分支才触发

jobs:
  deploy:
    runs-on: ubuntu-latest
    permissions:
      contents: write  # 必须：允许 Actions 向仓库写入（gh-pages 分支）

    steps:
      - uses: actions/checkout@v4
        with:
          submodules: false   # 若误把 book/ 登记成 submodule 且无 .gitmodules，拉子模块会失败；显式关闭更稳妥

      - name: Install mdBook
        uses: peaceiris/actions-mdbook@v2
        with:
          mdbook-version: "latest"   # 可固定版本号，如 "0.4.52"（需与本地/插件兼容时再考虑）

      - name: Build
        run: mdbook build

      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./book        # 只发布构建产物，勿把整个仓库推到 gh-pages
          # force_orphan: true      # 可选：每次用单提交覆盖 gh-pages，清掉历史上误提交的源码/混杂文件

8.3 GitHub Repository Settings

  1. 1. Open the repository → Settings → Pages
  2. 2. For Source, select Deploy from a branch
  3. 3. For Branch, select gh-pages, and for the directory select / (root)
  4. 4. Click Save

Choose the correct Pages source:

  • Do not use main + /docs: it runs Jekyll (logs often show jekyll-build-pages, Source: .../docs). Without a Jekyll project, it reports that the /docs directory does not exist.
  • Do not use main + / (root): GitHub still processes the repository with Jekyll, and the homepage is often README.md, which looks like a “single-page document”, not the mdBook book interface. Online reading must use the static files on gh-pages.
  • Correct: gh-pages + / (root) (the previous section's deploy.yml pushes ./book/ to gh-pages).

After the first git push main, wait for Actions to finish (about 1–2 minutes), then visit:

https://<你的用户名>.github.io/<仓库名>/

8.4 Workflow Explanation

git push main
     │
     ▼
GitHub Actions 触发
     │
     ├─ actions/checkout@v4        # 拉取代码（submodules: false）
     ├─ peaceiris/actions-mdbook@v2 # 安装 mdBook 二进制
     ├─ mdbook build               # 编译 → ./book/
     └─ peaceiris/actions-gh-pages@v4
           └─ 将 ./book/ 推送到 gh-pages 分支
                    │
                    ▼
           GitHub Pages 自动部署

9. .gitignore Configuration

The build output directory book/ should be ignored to avoid:

  • Committing large numbers of generated files to main;
  • Accidentally registering book/ as a Git submodule (if the index contains mode 160000 with no .gitmodules, CI reports No url found for submodule path 'book').
# mdBook 构建输出（勿提交；勿误登记为 submodule）
book/

Summary

After this process, you have a technical knowledge base with automated publishing, full-text search, dark mode support, free hosting. From then on, edit Markdown on main and git push; Actions runs mdbook build again and updates gh-pages. Readers must access the gh-pages root directory configured in Pages to reach the mdBook site.
