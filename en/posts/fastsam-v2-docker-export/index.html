Full-Stack Image Segmentation with SAM 2.1, V2: Docker Deployment and Export

Eva·2026.04.07·3 min read

Original length: 692 Chinese characters; approximately 4 minutes to read.

FastSAM-Demo is an interactive image-segmentation web application built on Meta SAM 2.1. Upload an image and click a target region to segment it in real time. This update adds one-command Docker deployment and three export modes.

Use cases:

  • Content creation and design: Quickly cut out subjects, replace backgrounds, and extract objects without professional Photoshop skills.
  • Furniture e-commerce: Upload a product photo, isolate the furniture in one click, remove distracting backgrounds, and create white-background or composite scene assets to improve product imagery.
  • Data annotation: Generate mask annotations in batches for machine-learning tasks such as object detection and instance segmentation.
  • Research and teaching: Demonstrate SAM 2.1, assess segmentation quality, and quickly produce figures for papers.
  • Prototyping: Add segmentation to your own image-processing pipeline and quickly validate a proof of concept.
  • Private local processing: Run entirely offline, including in settings with data-compliance requirements such as medical imaging and industrial quality inspection.

🐳 New: Docker Deployment

One-command Docker deployment is now supported. There is no need to configure Python environments or Node versions manually, or resolve dependency conflicts before getting started.

Use cases:

  • Quickly prepare a demo on a new machine or server.
  • Standardize development and test environments across a team to avoid “it works on my machine.”
  • Integrate into CI/CD pipelines and get started in restricted environments where Python or Node cannot be configured directly.

New Files

FileDescription
backend/DockerfilePython 3.11 + uv + FastAPI + SAM 2.1
frontend/DockerfileNode 20 + Next.js 15 standalone mode
docker-compose.ymlService orchestration on ports 3001/8001
.dockerignoreExcludes unrelated files to reduce image size

Startup Command

docker-compose up --build
  • Frontend: http://localhost:3001
  • Backend: http://localhost:8001

The backend uses uv for dependency management, with significantly faster installation than pip. The frontend uses Next.js 15 standalone builds for a smaller image and faster startup.

📥 New: Export

After segmentation, you can now export the results directly as PNG images in three modes for different downstream uses.

ModeDescriptionTypical uses
OriginalThe uploaded source imageArchiving and comparison
OverlayOriginal image with colored masks at 50% opacityDemos, annotation review, and paper figures
Mask onlyMasks on a black backgroundBackground replacement, object detection, and dataset creation
  • Availability: The Export button appears when a segmentation result is available.
  • Mask colors: Red, orange, yellow, green, cyan, blue, purple, and pink cycle through eight colors to distinguish multiple objects automatically.
  • Export format: PNG (lossless).
  • Exported overlay image
  • Exported mask-only image

✍️ Closing Thoughts

Both changes serve the same goal: making FastSAM-Demo easier to use. Docker lowers the barrier to getting it running; export completes the final step of using its results elsewhere.

The project is fully open source. Stars, forks, and issues are welcome.
